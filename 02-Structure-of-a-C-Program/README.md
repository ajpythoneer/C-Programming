## 🎯 Learning Outcomes

After completing this lecture, students should be able to:

- Identify and explain the major components of a C program.
- Explain the purpose of header files and preprocessor directives.
- Understand the role of the `main()` function.
- Explain statements, expressions, and program blocks.
- Understand the purpose of `printf()` and `return`.
- Describe how a C program is translated and executed.
- Write a basic C program following the standard structure.
