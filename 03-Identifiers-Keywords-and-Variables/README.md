## 🎯 Learning Outcomes

After completing this lecture, students should be able to:

- Explain what identifiers are in C.
- Identify the rules for creating valid identifiers.
- Distinguish between valid and invalid identifiers.
- Explain the purpose of keywords in C.
- Identify commonly used C keywords.
- Explain what variables are and why they are required.
- Declare and initialize variables in a C program.
- Apply appropriate naming conventions when creating variables.
- Differentiate between identifiers, keywords, and variables.
